# Backlog de entrada de novos projetos

Data da revisão: 2026-07-17

Este documento evita publicar um projeto antes de existir prova visual segura, descrição verificável e estado comercial claro.

## Critério de entrada

Um projeto só entra em `src/data/projects.ts` quando tiver:

1. nome e posicionamento aprovados;
2. URL pública ou prova privada sanitizada;
3. captura real com pelo menos 1200 × 675;
4. métricas verificáveis, sem números ilustrativos;
5. CTA principal válido;
6. autorização para exposição do cliente e do produto.
